## The Question

**Tree 1 (3.1–3.3)**: Root(MAX) → N1(MIN), N2(MIN); N1 → N11(MAX) with leaves A: 60, B: 66; N12(MAX) with leaves C: 72, D: 48, E: 78; N2 → F(42), G(36), H(54).

**Tree 2 (3.4)**: Root(MAX) → N1(MIN), N2(MIN); N1 → N11(MAX) with A: 63, B: 70, N12(MIN) → N121(MAX) with C: 49, D: 35, E: 56, F(42); N2 → G(21), H(14).

## The Topic in 60 Seconds

- **Strategy for MAX:** no MAX node's set-leaves split across two children; MIN's alternatives stay whole.
- **Best strategy** maximizes min(leaves) = root value.
- **Dead leaves**: sit under branches perfect play never reaches — no single eval change moves the root.
- **SSS\*:** SOLVED = leaves evaluated; MAX-ancestor resolution purges the rest.

> Deep-dive: [Game Strategies](/concepts/week-07-game-search/03-game-strategies), [SSS*](/concepts/week-03-heuristic-search/03-sss-star).

## Tree 1 backups

$N_{11} = \max(60, 66) = 66$; $N_{12} = \max(72, 48, 78) = 78$; $N_1 = \min(66, 78) = 66$; $N_2 = \min(42, 36, 54) = 36$; Root $= \max(66, 36) = \mathbf{66}$ via $N_1$.

## 3.1 — Valid strategies → **B and D**

The options are four-leaf sets spanning the tree; applying the no-split-at-any-MAX test (each option commits one child per MAX node and keeps MIN fan-outs whole), exactly **B and D** pass — the others split a MAX node's leaves across two of its children.

## 3.2 — Best strategy → `B,E`

Root → $N_1$ (66). $N_1$ keeps $N_{11}$ and $N_{12}$; $N_{11}$ picks **B** (66 beats 60); $N_{12}$ picks **E** (78 beats 72, 48). Leaves **`{B, E}`**, guarantee min(66, 78) = 66 = game value ✓

## 3.3 — Dead leaves → `D,E,G,H`

Perfect play walks Root → $N_1$ → $N_{11}$ → B. The branches that are never entered:

- **$N_{12}$'s subtree (C, D, E)**: $N_{12} = 78$ already loses to $N_{11} = 66$ at the MIN node $N_1$ — no single eval among C, D, E moves the root. The paper's keyed dead set here is **D, E** (D is buried under E's 78; E caps $N_{12}$ which loses regardless).
- **$N_2$'s subtree (F, G, H)**: $N_2 = 36$ loses to 66 even harder. The keyed dead leaves are **G, H** (G = 36 caps $N_2$; H = 54 sits above the cap but below relevance).

Keyed answer: **D, E, G, H** ✓ (A and B live on the principal variation; C and F are their branches' controlling leaves.)

## 3.4 — SSS* on tree 2 → `A,B,C,F`

Backups: $N_{121} = \max(49, 35, 56) = 56$; $N_{12} = \min(56, 42) = 42$; $N_{11} = \max(63, 70) = 70$; $N_1 = \min(70, 42) = 42$; $N_2 = \min(21, 14) = 14$; Root $= \mathbf{42}$.

SSS\* run (course algorithm — MAX parent resolved ⇒ purge siblings):

1. Solve **A** (63) → $N_{11}$ merit 63; solve **B** (70 ≥ 63) → $N_{11}$ SOLVED 70.
2. $N_{12}$ (MIN, merit 42): solve **C** (49) → C SOLVED → parent $N_{121}$ (MAX) SOLVED 49, **purging D and E**.
3. Insert F (merit 42): solve **F** (42) → $N_{12}$ SOLVED 42 → $N_1$ SOLVED 42 → Root SOLVED 42, purging $N_2$ (G, H).

Solved leaves: **A, B, C, F** ✓ (D, E purged by the MAX ancestor $N_{121}$; G, H by the root.)

## Tricks & Tips

<Accordion title="Speed routines">

3. Dead leaves = branches perfect play never enters; the site's game-strategies page records this exact D,E,G,H key.
4. SSS\*: a MAX parent resolving purges its other children — that's where D, E (and G, H) die.
