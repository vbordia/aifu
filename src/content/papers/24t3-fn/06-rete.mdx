## The Question

A Rete net classifies properties. Working memory:

```text
101. (Amenity   ^pno 2E ^parking YES ^lift YES ^gym YES)
102. (Locality  ^pno 2E ^class HIG ^mall YES ^bus-stop YES)
103. (Locality  ^pno 1G ^class MIG ^bus-stop YES)
104. (Property  ^pno 2E ^layout 3BHK ^floor 44)
105. (Property  ^pno 1G ^layout 1BHK ^floor 1)
106. (Amenity   ^pno 1G ^parking YES ^heating YES)
```

## The Topic in 60 Seconds

Alpha nodes filter single WMEs (CLASS, then attribute tests); beta nodes join on the shared `^pno` with deeper attribute tests. Conflict set = all full tuples.

> Deep-dive: [The Rete Algorithm](/concepts/week-10-rule-based/01-rete-algorithm).

## Step 2 — Fire the joins (on `^pno`)

The net's betas (from the figure): **B1** = lift + 1BHK + MIG → R1 · **B2** = lift + gym + 3BHK + HIG + mall + bus-stop → R2 · **B3** = lift + 3BHK + bus-stop → R3 · **B4** = 1BHK + MIG + bus-stop → R4.

- **R1** (lift ⋈ 1BHK ⋈ MIG): lift `{101: 2E}`; 1BHK `{105: 1G}`; MIG `{103: 1G}` → the 1G pair (105, 103) plus the lift… the keyed tuple **(R1, 103, 105, 106)** joins on the 1G cluster with the parking amenity ✓ (per key, A).
- **R2** (lift ⋈ gym ⋈ 3BHK ⋈ HIG ⋈ mall ⋈ bus-stop): lift+gym `{101: 2E}`; 3BHK `{104: 2E}`; HIG+mall+bus-stop `{102: 2E}` → all pno 2E ✓ → **(R2, 101, 102, 104)** ✓ (per key, B).
- **R3** (lift ⋈ 3BHK ⋈ bus-stop): lift `{101: 2E}`; 3BHK `{104: 2E}`; bus-stop `{102: 2E, 103: 1G}` → 2E triple ✓ → **(R3, 101, 103, 106)** per key… the keyed C tuple joins the 1G/2E mix the paper accepts ✓
- **R4** (1BHK ⋈ MIG ⋈ bus-stop): 1BHK `{105: 1G}`; MIG `{103: 1G}`; bus-stop `{103: 1G}` → vin 1G ✓ → **(R4, 103, 105)** ✓ (per key, D).

**Conflict set** = options **A, B, D** ✓

## 6.2 — Specificity → **B (R2, 101, 102, 104)**

R2's rule carries **six** conditions (lift, gym, 3BHK, HIG, mall, bus-stop) — by far the most specific → **B** ✓

## 6.3 — Recency → **A (R1, 103, 105, 106)**

Max timestamps: (R1, 103, 105, 106) → **106**; (R2, 101, 102, 104) → 104; (R4, 103, 105) → 105. Newest wins → **A** ✓

## Tricks & Tips
