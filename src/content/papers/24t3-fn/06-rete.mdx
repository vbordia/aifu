## The Question

A Rete net classifies properties. Working memory:

```text
101. (Amenity   ^pno 2E ^parking YES ^lift YES ^gym YES)
```

## The Topic in 60 Seconds

Alpha nodes filter single WMEs (CLASS, then attribute tests); beta nodes join streams on the shared `^pno`. Conflict set = all fully matched (rule, data…) tuples.

> Deep-dive: [The Rete Algorithm](/concepts/week-10-rule-based/01-rete-algorithm).

## Step 1 — Locate every WME

Split WM by `^pno` first — tuples never cross clusters:

| Cluster | WMEs | Contents |
|---------|------|----------|
| **2E** | 101, 102, 104 | Amenity (parking/lift/gym) · Locality (HIG/mall/bus-stop) · Property (3BHK/floor 44) |
| **1G** | 103, 105, 106 | Locality (MIG/bus-stop) · Property (1BHK/floor 1) · Amenity (parking/heating) |

Alpha-level notes: heating (WME 106) has no alpha node — the WME still sits in the parking leaf; floor 44 passes the floor > 10 test, floor 1 does not.

## Step 2 — Test each option tuple at its beta joins

| Option | Tuple | Join check | Verdict |
|--------|-------|------------|---------|
| **A** | (R1, 103, 105, 106) | all `^pno` = **1G**: MIG (103) ⋈ 1BHK (105) ⋈ parking-amenity (106) ✓ | **in** |
| **B** | (R2, 101, 102, 104) | all `^pno` = **2E**: lift+gym (101) ⋈ 3BHK (104) ⋈ HIG+mall+bus-stop (102) ✓ | **in** |
| C | (R3, 101, 103, 106) | 101 lives at 2E but 103/106 at 1G — **mixed cluster**, no shared `^pno` join | out |
| **D** | (R4, 103, 105) | all `^pno` = **1G**: MIG+bus-stop (103) ⋈ 1BHK (105) ✓ | **in** |

**Conflict set** = options **A, B, D** ✓

## 6.2 — Specificity → **B**

Count conditions (= WMEs bound in the tuple): R2's rule fires through six joined tests (lift, gym, 3BHK, HIG, mall, bus-stop); R1 carries three; R4 carries three. Most specific wins → **B** ✓

## 6.3 — Recency → **A**

Newest WME inside each surviving tuple:

| Tuple | Max timestamp |
|-------|---------------|
| **A** (R1, 103, 105, 106) | **106** ← newest in WM |
| B (R2, 101, 102, 104) | 104 |
| D (R4, 103, 105) | 105 |

Highest timestamp wins → **A** ✓

## Tricks & Tips

<Accordion title="Deduction shortcuts for this exact net">
1. Split WM into the 2E and 1G clusters before anything else. Any option mixing clusters (C: 101 with 103/106) is dead on arrival — no beta can join across different property numbers.
2. Count how many option tuples each cluster supports: 2E backs exactly one full tuple (B); 1G backs two (A and D). That's your conflict set of three without touching a single rule body.
3. Specificity is just condition-counting — six tests beat three, so B. Don't overthink rule semantics.
4. Recency scan: find the highest timestamp in working memory (106, the last WME), then ask which surviving tuple contains it — A. Two minutes for the whole question.
</Accordion>
