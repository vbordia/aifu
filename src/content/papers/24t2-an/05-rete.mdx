## The Question

A Rete net classifies machines. Working memory:

```text
101. (Cargo     ^vin A1 ^bed flat)
102. (Passenger ^vin A1 ^limit 2)
103. (Passenger ^vin B2 ^limit 8)
104. (Passenger ^vin C3 ^limit 2)
105. (Power     ^vin A1 ^hp 400)
106. (Power     ^vin B2 ^hp 250)
107. (Power     ^vin C3 ^hp 900)
108. (Wheel     ^vin B2 ^tyre regular)
109. (Wheel     ^vin C3 ^tyre regular)
```

|---|----------|-----------------|
| 5.1 | Tuples in the conflict set (A: Luxury-Car,104,107 · B: Minivan,103,106 · C: Truck,101,102,105 · D: Minivan,103,106,108) | **A, B, C** |
| 5.2 | Specificity fires | **C** |
| 5.3 | Recency fires | **A** |

## The Topic in 60 Seconds

Alpha nodes filter single WMEs; beta nodes join on the shared `^vin`. Conflict set = all full tuples. **Specificity** = most conditions; **Recency** = newest max-timestamp.

> Deep-dive: [The Rete Algorithm](/concepts/week-10-rule-based/01-rete-algorithm).

## 5.2 — Specificity → **C**

Condition counts: Luxury = 2, Minivan = 2, **Truck = 3** (bed + limit-2 + hp ≤ 500) → most conditions → **(Truck, 101, 102, 105)** → option **C** ✓

## 5.3 — Recency → **A**

Max timestamps: Luxury-Car → **107**; Minivan → 106; Truck → 105. Newest wins → **(Luxury-Car, 104, 107)** → option **A** ✓

## Tricks & Tips

<Accordion title="4-step recipe">
1. Alpha-table every WME first: 108/109 are Wheel WMEs and this net has no Wheel rule — they are dead weight (and option D's bait).
2. Join on `^vin` pairwise per rule: Luxury needs ONE shared vin between limit-2 and hp≥700 (only C3 works); Truck chains three WMEs that must ALL be A1.
3. Specificity: count conditions — Truck's 3 beat the 2-condition rivals outright.
4. Recency: take each surviving tuple's MAX timestamp and compare (107 &gt; 106 &gt; 105) — the newest WME anywhere in the tuple decides.
</Accordion>

**Answers:** 5.1 **A, B, C** · 5.2 **C** · 5.3 **A**
