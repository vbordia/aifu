Standard one-armed Blocks World operators.

**Start state:** onTable(B), onTable(A), onTable(E), clear(D), clear(C), clear(E), on(D,B), on(C,A), armEmpty

**Goal:** on(A,C), on(B,A)

## The Topic in 60 Seconds

**Applicable** = preconditions ⊆ state. **Relevant** = add-list ∩ goal ≠ ∅. $A_1$ = applicable in $P_0$ (+no-ops). **Action mutex** (ANY): effects / interference / needs. **Proposition mutex** (ALL): every producer pair mutex.

> Deep-dive: [Blocks World & STRIPS](/concepts/week-08-planning/01-blocks-world-strips), [GraphPlan Mutexes](/concepts/week-09-goal-trees/02-graphplan-mutexes).

## 7.1 — Applicable → **B, C, D**

armEmpty holds:

| Action | Preconditions | Verdict |
|--------|---------------|---------|
| Putdown(D) | holding(D) ✗ | ✗ |
| **Unstack(D,B)** | armEmpty ✓, clear(D) ✓, on(D,B) ✓ | **✓** |
| **Unstack(C,A)** | armEmpty ✓, clear(C) ✓, on(C,A) ✓ | **✓** |
| **Pickup(E)** | armEmpty ✓, clear(E) ✓, onTable(E) ✓ | **✓** |
| Pickup(A) | clear(A) ✗ (C on A) | ✗ |
| Stack(B,A) / Stack(A,C) | holding(·) ✗ | ✗ |

## 7.2 — Relevant → **F, G**

Goal = on(A,C), on(B,A): **Stack(A,C)** adds on(A,C) ✓; **Stack(B,A)** adds on(B,A) ✓.

## 7.3 — Mutex action pairs → **A, B**

$A_1$ = ( Unstack(D,B), Unstack(C,A), Pickup(E) ) + no-ops (options C, D name inapplicable Stacks).

- Unstack(D,B) ⊕ Pickup(E): both **delete armEmpty** → interference → mutex ✓
- Unstack(D,B) ⊕ Unstack(C,A): same → mutex ✓

## 7.4 — Mutex propositions → **A, B**

$P_1$ = start facts (nops) ∪ adds: clear(B), clear(A), holding(D), holding(C), holding(E).

| Pair | Producers | Verdict |
|------|-----------|---------|
| **clear(B) ⊕ holding(C)** | clear(B): only Unstack(D,B); holding(C): only Unstack(C,A) — producers mutex | **✓** |
| **clear(B) ⊕ clear(A)** | clear(A): only Unstack(C,A) — same mutex pair | **✓** |
| clear(E) ⊕ on(D,B) | clear(E) is a **start fact** → clean no-op | Not mutex |
| clear(E) ⊕ holding(D) | same clean no-op | Not mutex |

## Tricks & Tips

<Accordion title="One minute each">
1. Applicable: armEmpty ⇒ unstacks/pickups only.
2. Relevant: add-list ∩ goal.
3. Layer-1 mutex: armEmpty interference.
4. Proposition mutex: start facts escape via no-ops; single-producer facts are locked.
</Accordion>

**Answers:** 7.1 **B, C, D** · 7.2 **F, G** · 7.3 **A, B** · 7.4 **A, B**
