## The Question

Same junction dictionary (L1–L6, W1–W3, Y1–Y3, T1–T4, rotations allowed). A six-junction drawing to label.

```text
     3 --------- 4 --------- 5
     | \       / |           |
     |  \     /  |           |
     |   \   /   |           |
     |     1     |           |
     |   /   \   |           |
     |  /     \  |           |
     | /       \ |           |
     2 --------- 6 -----------
```

**Official answer:** `NIL`

## The Topic in 60 Seconds

Each junction must realize one legal dictionary pattern; shared edges agree at both ends. Empty domain ⇒ NIL.

> Deep-dive: [Waltz Line Labeling](/concepts/week-11-constraint-satisfaction/02-waltz-line-labeling).

## Step 0 — Count edges per junction

| Junction | Incident edges | Degree | Legal types |
|----------|----------------|--------|-------------|
| 3 | 4, 2, 1 | 3 | W / Y / T |
| 4 | 3, 5, 1 | 3 | T (collinear bar 3-4-5 + stem) |
| 5 | 4, 6 | 2 | L |
| **1** | **3, 4, 2, 6** | **4** | **none** |
| 2 | 3, 1, 6 | 3 | W / Y / T |
| 6 | 5, 2, 1 | 3 | W / Y / T |

The dictionary only contains L (2 edges), T/W/Y (3 edges each). Junction 1 has a **fourth spoke**: the drawing connects it to 3 and 4 (upper diagonals) *and* to 2 and 6 (lower diagonals).

## Why the answer is NIL

1. A CSP assignment needs a dictionary pattern for **every** junction. Junction 1's domain starts empty: no L, W, Y or T pattern has four incident edges, no rotation fixes that, and no neighbor can remove an edge for it.
2. Propagation never even gets a chance — the wipe-out is at the initial domain, not mid-search. Every other junction could label fine (T4 would fire its two outward bar arrows on 3-4 and 4-5, the L at 5 takes a matching arrow), but one unassignable junction makes the whole labeling inconsistent.
3. So the drawing cannot come from a trihedral scene → **`NIL`** ✓

Exam takeaway: before propagating anything, count edges at every junction. A 4-edge fan is an instant NIL.

## Tricks & Tips

<Accordion title="The 4-step Waltz exam method">
1. Classify every junction by counting edges first (2 = L; collinear pair + stem = T; fan = W; ~120° trio = Y).
2. If any junction has 4+ edges, stop: the dictionary caps out at 3 — answer NIL immediately, as with junction 1 here.
3. Otherwise force the T first (bar arrows point outward), then propagate along shared edges.
4. First emptied domain ends the question; full consistency means the answer is the label list itself.
</Accordion>

**Answer:** 8.1 `NIL`
