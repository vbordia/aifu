**6** — Which of the following are true about the Branch-and-Bound method (discussed in the lecture) that is used for finding optimal tours for the Traveling Salesman Problem?

Options:

| Option | |
|---|---|
| **A** | The root of the search tree represents all possible tours. |
| **B** | The root of the search tree represents the shortest/optimal tour. |
| **C** | Each node in the search tree represents a set of tours. |
| **D** | Each node in the search tree represents a single tour. |
| **E** | The costs of the search tree nodes monotonically INCREASE from the root to leaf. |
| **F** | The costs of the search tree nodes monotonically DECREASE from the root to leaf. |

**Answer:** **A**, **C**, **E**
