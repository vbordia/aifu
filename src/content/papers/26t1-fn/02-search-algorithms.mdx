## Solutions

**2.1** — Which of the following variants of Depth First Iterative Deepening (DFID) is guaranteed to find the shortest path if one exists?

Options:

| Option | |
|---|---|
| **A** | DFID that inspects only new nodes. |
| **B** | DFID that inspects new as well as open nodes. |
| **C** | DFID that inspects new as well as closed nodes. |
| **D** | None of these. |

**Answer:** **C**

**2.2** — Given a finite state space with edge costs that may or may not be Euclidean and a heuristic function whose properties are not known, which of the following algorithms are suitable for finding the optimal path?

Options:

| Option | |
|---|---|
| **A** | Depth First Search |
| **B** | Breadth First Search |
| **C** | Dijkstra's algorithm |
| **D** | Branch and Bound Search |
| **E** | A* |
| **F** | WA* for some w |
| **G** | Sparse Memory Graph Search (SMGS) |

**Answer:** **C**, **D**

**2.3** — If w is set to zero then wA* algorithm will __________ .

Options:

| Option | |
|---|---|
| **A** | behave like Best-First Search |
| **B** | behave like Dijkstra's algorithm |
| **C** | always find the optimal path |
| **D** | sometimes find a suboptimal path |

**Answer:** **B**, **C**
