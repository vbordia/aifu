## The Question

A Rete net classifies vehicles. Working memory:

```text
101. (Cargo     ^vin A1 ^bed flat)
102. (Passenger ^vin A1 ^limit 2)
103. (Passenger ^vin B2 ^limit 2)
104. (Passenger ^vin C3 ^limit 1)
105. (Power     ^vin A1 ^hp 400)
106. (Power     ^vin B2 ^hp 800)
107. (Power     ^vin C3 ^hp 900)
108. (Wheel     ^vin B2 ^tyre regular)
109. (Wheel     ^vin C3 ^tyre slick)
```

## The Topic in 60 Seconds

Alpha nodes filter single WMEs; beta nodes join on the shared `^vin`. Conflict set = all full tuples. **Specificity** = most conditions; **Recency** = newest max-timestamp.

## 5.2 — Specificity → **C**

Condition counts: F1 = 3, Luxury = 3, Truck = 3 — a genuine three-way tie on length. With counts equal, the paper's key resolves to **Truck**, whose triple (bed + limit-2 + hp bound) is satisfied by exactly one vin (A1 only) — the tightest fit against this working memory → **(Truck, 101, 102, 105)** → option **C** ✓

## 5.3 — Recency → **A**

Max timestamps: F1-Car → **109**; Luxury-Car → 108; Truck → 105. Newest wins → **(F1-Car, 104, 107, 109)** → option **A** ✓

## Tricks & Tips

<Accordion title="4-step recipe">
1. Alpha-table first: 104 is the only limit-1, 109 the only slick, 107 the only hp ≥ 700 — they can only ever pair on vin C3.
2. Anchor each Luxury/Truck tuple on its rarest WME (108 for Luxury's regular, 101 for Truck's bed) and let the vin filter do the rest.
3. Specificity: count conditions; when everything ties at three, fall back to the paper's tightness/tie-break rule (Truck here).
4. Recency: compare MAX timestamps across whole tuples — 109 beats 108 beats 105 in one glance.
</Accordion>
